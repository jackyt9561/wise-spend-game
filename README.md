## Enhanced standalone semester game

- Open `/home/runner/work/wise-spend-game/wise-spend-game/enhanced-game.html` directly in a browser (no build step required).
- This version is self-contained (inline CSS/JavaScript) and keeps the original `index.html` unchanged.
- Learning objectives:
  - distinguish recurring essentials, flexible spending, and emergency savings
  - practice trade-off decisions under monthly budget pressure
  - understand emergency-fund use, debt borrowing, and interest consequences
  - balance financial decisions with wellbeing and academic sustainability
